Miro Terminal

Terminals live on the board as widgets. Each one runs on somebody's own machine — whoever created it — and everyone else sees the commands it ran, read from the board.

Nothing to set up to read them. Having this app installed is all a terminal's history needs. It stays readable even when the machine running it is off.

Run your own terminals

Three things, once. Terminals you create then appear on any board you open.

  1. Run the terminal server on your machine, over HTTPS with a certificate your browser trusts. An untrusted certificate fails silently — a warning cannot be shown inside a board — so use mkcert and install its CA.
  2. Save its address below. Kept in this browser only; every person runs their own.
  3. Install the relay app and click its icon once. That is a second Miro app, served from your machine, and it is what lets a terminal on the board be typed into — a public page cannot reach your computer, so the relay holds the connection on its behalf. Set EMBED_ORIGINS in its .env or it will refuse to connect.

Terminal server

Create a terminal

Opens the spawner, served from your own machine — which is what lets it browse your folders. The relay app's icon opens it too.

Once a terminal is on the board, connect a card or sticky to it with a connector and type [INPUT] in the terminal to pull in its text. Caption the connector to address that item by name instead.
